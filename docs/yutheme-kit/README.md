# YuTheme v2 kit

The complete, stack-independent YuTheme this app is built on, packaged for the
`yutheme-design-system` Hermes skill (installed into `assets/` and `references/`
of that skill).

- `assets/yutheme-kit.css`: standalone stylesheet (tokens for AMOLED, graphite
  and app-only daylight, base, components, the full effect set, reduced motion).
- `assets/yutheme-tokens.json`: the same tokens and motion numbers as data.
- `assets/kit-preview.html`: living specimen (open it next to the CSS).
- `references/theme-kit.md`: the theme as a system and how to apply it per
  product type and stack.
- `references/mockups/yutheme-2.0-surfaces-effects/`: the approved design
  mockup (serve the folder and open `Tokens.dc.html`).

The WebUI's own `apps/web/src/styles.css` is the Tailwind v4 implementation of
the same system.
